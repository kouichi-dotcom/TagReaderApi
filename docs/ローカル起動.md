# TagReaderApi のローカル起動（ローカル DB / 本番 DB）

作業ディレクトリ: `C:\dev\TagReaderApi`  
待受: `http://localhost:5262`

アプリ側の起動と組み合わせる場合は、`C:\dev\tag_reader_app\docs\起動コマンド一覧.md` を参照。

## ローカル DB（Development）

```powershell
cd C:\dev\TagReaderApi
dotnet run --launch-profile http
```

- `launchSettings.json` の `http` プロファイル（`ASPNETCORE_ENVIRONMENT=Development`）
- 接続文字列: `appsettings.Development.json` の `ConnectionStrings:DefaultConnection`
- 確認: `http://localhost:5262/api/environment` → `Development`

## 本番 DB（Production）

```powershell
cd C:\dev\TagReaderApi
dotnet run --launch-profile http-production
```

- `http-production` プロファイル（`ASPNETCORE_ENVIRONMENT=Production`）
- 接続文字列: `appsettings.Production.json`
- 確認: `http://localhost:5262/api/environment` → `Production`
- 本番データを更新しうる操作は慎重に

## プロファイル未指定

```powershell
dotnet run
```

`Program.cs` により未設定時は `Development`（ローカル DB）になる。本番 DB にするときは必ず `--launch-profile http-production` を付ける。
