# Azure サブスクリプション・リソースグループの準備

A 案（API のみクラウド）で App Service を利用するために、Azure のサブスクリプションとリソースグループを用意する手順。**既存のサブスクリプション・リソースグループがあれば流用してよい。**

---

## 1. サブスクリプションの確認・準備

| # | 手順 | 補足 |
|---|------|------|
| 1-1 | **Azure ポータルにログイン** | https://portal.azure.com にアクセス。Microsoft アカウントまたは Azure AD アカウントでサインイン。 |
| 1-2 | **サブスクリプションの有無を確認** | ポータル上部の検索で「サブスクリプション」を検索 → **サブスクリプション** を開く。一覧に表示されていれば既存のサブスクリプションがある。 |
| 1-3 | **既存がある場合** | 利用するサブスクリプションを選ぶ（課金はこのサブスクリプションに紐づく）。ここで終了し、次の「2. リソースグループ」へ。 |
| 1-4 | **新規で作成する場合** | [Azure の無料アカウント](https://azure.microsoft.com/free/) から作成するか、社内で発行されたサブスクリプションを利用する。無料アカウントでは一定枠まで無料（F1 の App Service は無料枠の対象）。 |

---

## 2. リソースグループの作成

App Service や今後追加するリソース（Key Vault 等）をまとめて管理するための**リソースグループ**を 1 つ作る。

| # | 手順 | 補足 |
|---|------|------|
| 2-1 | **リソースグループ作成画面を開く** | ポータル検索で「リソースグループ」→ **作成**。または **ホーム** → **リソースの作成** → **リソースグループ**。 |
| 2-2 | **サブスクリプション** | 手順 1 で決めたサブスクリプションを選択。 |
| 2-3 | **リソースグループ名** | 例: `rg-tagreader-prod`（任意。後から App Service 名などで識別できる）。 |
| 2-4 | **リージョン** | 例: **東日本**（Japan East）または **西日本**（Japan West）。自社 DB や利用者に近いリージョンを選ぶ。F1 はリージョンによって利用可否が異なる場合がある。 |
| 2-5 | **確認および作成** → **作成** | 作成後、リソースグループ一覧に表示される。 |

---

## 3. 確認

- **サブスクリプション**: 課金・アクセス制御の単位として認識できていること。
- **リソースグループ**: 一覧に表示され、名前・リージョンが想定どおりであること。

次のステップでは、このリソースグループ内に **App Service（Web アプリ）** を作成する（[アプリ公開までのすべきこと.md](./アプリ公開までのすべきこと.md) の 2. Azure App Service の作成）。
