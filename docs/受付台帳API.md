# 受付台帳 API

## エンドポイント

- **GET** `/api/reception-slips`

### クエリパラメータ

| パラメータ | 型 | 説明 |
|-----------|-----|------|
| `date` | DateTime? | 期日（yyyy-MM-dd）。省略時は**期日の直近1ヶ月**（`Today.AddMonths(-1)` 以降・期日の新しい順） |
| `assigneeCode` | string? | 担当者コード（配達担当）。処理者と一致する伝票を表示 |
| `unassignedOnly` | bool | `true`: 配達担当者未定の伝票のみ（処理者未入力）。`false`: 処理者=assigneeCode の伝票 |
| `subjects` | string? | 用件で絞り込み（カンマ区切り）。例: `来店(納品),来店(返品)`。`assigneeCode` と併用可 |
| `excludeSubjects` | string? | 用件で除外（カンマ区切り）。例: `来店(納品),来店(返品)`（全伝票一覧・来店以外用） |
| `limit` | int | 取得件数（1〜50）。省略時 **10** |
| `offset` | int | 先頭からスキップする件数。省略時 **0**（ページング用） |

### 絞り込み条件

- **確認** … `0` のデータのみ（未確認）
- **期日** … **直近1ヶ月**（`期日 >= Today.AddMonths(-1)` かつ明日未満）。`date` 指定時はその期日かつ1ヶ月以内。期日が NULL の伝票は除外
- **キャンセル用件** … 用件コード `21`（ｷｬﾝｾﾙ(配達)）/ `22`（ｷｬﾝｾﾙ(引取)）/ `23`（ｷｬﾝｾﾙ）は常に除外
- **通常モード** (`unassignedOnly=false`): **処理者** = `assigneeCode`（未指定時は担当者絞りなし）
- **未定モード** (`unassignedOnly=true`): **処理者** が未入力（NULL または空）
- **excludeSubjects** … 指定した用件名を除外（来店以外の全伝票一覧など）

## 想定している DB 構成（要確認・必要に応じて変更）

実際のテーブル名・列名が異なる場合は、`ReceptionSlipsController.cs` の SQL を修正してください。

### 受付台帳 `[受付台帳]`

| 列名 | 型 | 説明 |
|------|-----|------|
| 受付番号 | テキスト | そのまま表示 |
| 用件 | テキスト | |
| 顧客id | int | → 顧客台帳の顧客コードと紐付け |
| 顧客名その他 | テキスト | 顧客名（その他） |
| 現場コード | int? | → 現場台帳と紐付け。`99999` のとき現場台帳の現場名は「その他」。アプリ一覧では `[現場名（その他）]` を代替表示する |
| 現場名その他 | テキスト | 現場名（その他）。API は生データを返す。一覧の代替表示はアプリ側 |

| 期日 | datetime? | 一覧の絞り込み・並び順に使用（直近1ヶ月） |
| 期限コード | テキスト/int? | → 期限台帳と紐付け |
| 期限２ | テキスト | |
| メモ | テキスト | |
| 受付日時 | datetime | 表示用（一覧の期間条件には使わない） |
| 確認 | int | 0=未確認（表示対象） |
| 処理者 | テキスト | 担当者コード。未定の場合は NULL/空 |
| 用件コード | int | 用件台帳と紐付け。21/22/23（キャンセル系）は一覧から除外 |

### 顧客台帳 `[顧客台帳]`

| 列名 | 説明 |
|------|------|
| 顧客コード | 受付台帳.顧客id と一致 |
| 顧客名 | 表示用 |

### 現場台帳 `[現場台帳]`

| 列名 | 説明 |
|------|------|
| 現場コード | 受付台帳.現場コード と一致 |
| 現場名 | 表示用 |

### 期限台帳 `[期限台帳]`

| 列名 | 説明 |
|------|------|
| 期限コード | 受付台帳.期限コード と一致 |
| 期限 | 表示用 |

### 受付明細 `[受付明細]`

| 列名 | 説明 |
|------|------|
| 受付番号 | 受付台帳と同一 |
| 商品コード | → 商品台帳で商品名取得。ただし `[その他商品表示台帳]` にあるコードは受付明細の `[その他商品]` を商品名として返す（空なら「その他商品」） |
| 台数 | そのまま表示 |
| 単位コード | → 単位台帳で単位名取得 |

### 商品台帳 `[商品台帳]`

既存の商品台帳。商品コード → 商品名。

### その他商品表示台帳 `[その他商品表示台帳]`

商品コードがここに存在する明細は、一覧・詳細とも `[受付明細].[その他商品]` を商品名として返す。

### 単位台帳 `[単位台帳]`

| 列名 | 説明 |
|------|------|
| 単位コード | 受付明細.単位コード と一致 |
| 単位名 | 表示用 |
