# 受付台帳 API

## エンドポイント

- **GET** `/api/reception-slips`

### クエリパラメータ

| パラメータ | 型 | 説明 |
|-----------|-----|------|
| `date` | DateTime? | 受付日（yyyy-MM-dd）。省略時は**当日** |
| `assigneeCode` | string? | 担当者コード（配達担当）。処理者と一致する伝票を表示 |
| `unassignedOnly` | bool | `true`: 配達担当者未定の伝票のみ（処理者未入力）。`false`: 処理者=assigneeCode の伝票 |
| `subjects` | string? | 用件で絞り込み（カンマ区切り）。例: `来店(納品),来店(返品)`。`assigneeCode` と併用可。date 未指定時は全期間から最新順 |
| `limit` | int | 取得件数（1〜50）。省略時 **10** |
| `offset` | int | 先頭からスキップする件数。省略時 **0**（ページング用） |

### 絞り込み条件

- **受付日時** … 指定日（省略時は当日）のデータ
- **転記済み** … `0` のデータのみ
- **通常モード** (`unassignedOnly=false`): **処理者** = `assigneeCode`
- **未定モード** (`unassignedOnly=true`): **処理者** が未入力（NULL または空）

### 受付台帳 `[受付台帳]`

| 列名 | 型 | 説明 |
|------|-----|------|
| 受付番号 | テキスト | そのまま表示 |
| 用件 | テキスト | |
| 顧客id | int | → 顧客台帳の顧客コードと紐付け |
| 顧客名その他 | テキスト | 顧客名（その他） |
| 現場コード | int? | → 現場台帳と紐付け |
| 現場名その他 | テキスト | 現場名（その他） |
| 期日 | datetime? | |
| 期限コード | テキスト/int? | → 期限台帳と紐付け |
| 期限２ | テキスト | |
| メモ | テキスト | |
| 受付日時 | datetime | 絞り込みに使用 |
| 転記済み | int | 0=未転記（表示対象） |
| 処理者 | テキスト | 担当者コード。未定の場合は NULL/空 |

### 顧客台帳 `[顧客台帳]`

| 列名 | 説明 |
|------|------|
| 顧客コード | 受付台帳.顧客id と一致 |
| 顧客名 | 表示用 |

### 現場台帳 `[現場台帳]`

| 列名 | 説明 |
|------|------|
| 現場コード | 受付台帳.現場コード と一致 |
| 現場名 | 表示用 |

### 期限台帳 `[期限台帳]`

| 列名 | 説明 |
|------|------|
| 期限コード | 受付台帳.期限コード と一致 |
| 期限 | 表示用 |

### 受付明細 `[受付明細]`

| 列名 | 説明 |
|------|------|
| 受付番号 | 受付台帳と同一 |
| 商品コード | → 商品台帳で商品名取得 |
| 台数 | そのまま表示 |
| 単位コード | → 単位台帳で単位名取得 |

### 商品台帳 `[商品台帳]`

既存の商品台帳。商品コード → 商品名。

### 単位台帳 `[単位台帳]`

| 列名 | 説明 |
|------|------|
| 単位コード | 受付明細.単位コード と一致 |
| 単位名 | 表示用 |
