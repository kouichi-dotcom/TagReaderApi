# 2026年4月 DB 実測（API 通信量の根拠）

既存システムの 2026年4月データを集計し、1日あたりの件数を出した結果。  
API 使用量の見積もり（[API使用量と料金の見積もり.md](./API使用量と料金の見積もり.md)）の実測根拠として使う。

- 対象月: **2026年4月**
- 1日平均: **出勤日 20日** で割った値
- 集計日: 2026-08-20

### 使用した SQL

```sql
SELECT
    COUNT(*) AS april_count,
    COUNT(*) / 20.0 AS daily_avg
FROM [dbo].[tag_table3]
WHERE [read_time] >= '2026-04-01'
  AND [read_time] <  '2026-05-01';
```

```sql
SELECT
    CAST([read_time] AS date) AS read_date,
    COUNT(*) AS cnt
FROM [dbo].[tag_table3]
WHERE [read_time] >= '2026-04-01'
  AND [read_time] <  '2026-05-01'
GROUP BY CAST([read_time] AS date)
ORDER BY read_date;
```

## 2. [受付台帳]（受付日時）

4月に**作成された**受付伝票の件数。API の `GET /api/reception-slips` の呼び出し回数そのものではない（同じ伝票を複数回読む場合は API 回数の方が多くなる）。

### 集計結果

| 項目 | 値 |
|------|-----|
| `april_count` | 1286 |
| `daily_avg` | 64.300000 |

### 使用した SQL

```sql
SELECT
    COUNT(*) AS april_count,
    COUNT(*) / 20.0 AS daily_avg
FROM [dbo].[受付台帳]
WHERE [受付日時] >= '2026-04-01'
  AND [受付日時] <  '2026-05-01';
```

## API 見積もりとの対応

既存見積もり（多め前提）との比較。

| 見積もりの前提 | 見積もり | 4月実測 | メモ |
|----------------|----------|---------|------|
| 商品準備（ステータス更新） | 200回/日 | tag_table3 **約 159件/日** | 実測の方がやや少ない。見積もりは余裕側 |
| 伝票の読込 | 15人 × 20回 = 300回/日 | 伝票作成 **約 64件/日** | 指標が違う。作成件数 ≠ 一覧API回数 |

伝票 API は「作成 64件」に対し、担当者が一覧を何度も取るため、呼び出しは作成件数より多くなる。見積もりの 300回/日は、その再読込を多めに見た値。
