# 受付伝票タグ紐付け API

受付伝票に RFID で読んだタグを紐付け、既存 C#（Reception.cs）の転記処理が拾える形で DB に記録する。

記録日: 2026-09-11（引取分岐追記: 2026-09-14 / 交換分岐追記: 2026-09-15 / 来店分岐追記: 2026-09-15 / 納品明細返却追記: 2026-10-13）

---

## エンドポイント

- **POST** `/api/reception-slips/{receptionNo}/link-tags`

`{receptionNo}` は受付番号（数値文字列）。

---

## リクエスト Body（JSON）

| プロパティ | 型 | 必須 | 説明 |
|------------|-----|------|------|
| user_id | string | - | 担当者コード。整数変換できれば [tag_table3].[s_code] に記録 |
| link_mode | string | 用件「交換」のとき必須 | `交換納品` または `交換返品`。他用件では無視 |
| items | array | ○ | 紐付けるタグ（1 件以上） |
| items[].epc | string | ○ | タグ ID（[ICタグ台帳].[tag_id2]） |
| items[].product_code | string | - | 商品コード（任意。台帳・受付明細との不一致は警告のみ） |

### 例（配達・引取・来店）

```json
{
  "user_id": "51",
  "items": [
    { "epc": "e2801191a5040076252b752c", "product_code": "1234" }
  ]
}
```

用件が `<配達>` / `来店(納品)` なら納品モード、`引取` / `来店(返品)` なら返品モードで記録する（リクエスト Body は同じ）。

### 例（交換・交換納品）

```json
{
  "user_id": "51",
  "link_mode": "交換納品",
  "items": [
    { "epc": "e2801191a5040076252b752c", "product_code": "1234" }
  ]
}
```

## 処理内容

1 リクエスト＝1 受付。全体を 1 トランザクションで処理する。

1. `Database:ReadOnly=true` のときは **409**（書き込み不可）
2. 受付台帳に受付番号が無ければ **404**
3. 受付台帳の用件コードから [用件台帳] の用件を取得し、書き込みモードを決定（下表）。あわせて受付台帳の **顧客コード・現場コード** を取得（返品モードの納品明細更新用）
4. 用件が「交換」で `link_mode` が不正／未指定のときは **400**
5. 各 EPC が [ICタグ台帳] に無ければ **404**（全体ロールバック）
6. 各タグについて:
   - 同一受付＋同一 `tag_id2` で `complete=1` の行が **1 件でもあれば**既処理としてスキップ（**tag_mode は見ない**）。ICタグ台帳も tag_table3 も変更せず、warnings に「既に処理済みのためスキップしました。」を追加。`linked` には含めない  
     - **返品モード**ではこの場合でも [納品明細] の `[返却]=1` 未設定だけ再試行する（在庫戻し済みの再送で納品明細だけ直せる）
   - 上記以外（complete=1 が無い場合）:
     - [ICタグ台帳]: `tag_mode2` をモードに応じて更新、`updated` を秒単位で更新
     - 同一受付＋同一 `tag_id2` かつ `complete=0` の [tag_table3] 行を DELETE（再送対策）
     - [tag_table3] に INSERT（`印刷=0`, `mark=0`, `tag_mode` / `complete` はモードに応じた値, `受付番号`=パスの値）
     - **返品モード**のとき: 下記「納品明細の返却記録」を実行

納品伝票は更新しない。配達モードの番号付与・入れ替えは既存 Reception.cs の転記処理に任せる。

※ UNIQUE 制約は付けない（交換などで別 tag_mode の行が同居し得るため）。既処理判定は **受付番号 + EPC + complete=1** のみ。

### 用件による書き込みモード

| 用件（[用件台帳].[用件]） | link_mode | [ICタグ台帳].tag_mode2 | [tag_table3].tag_mode | complete | 納品明細 |
|---------------------------|-----------|------------------------|----------------------|----------|----------|
| `引取`（完全一致） | （不要） | `在庫` | `返品` | `1` | `[返却]=1`（下記） |
| `来店(返品)`（完全一致） | （不要） | `在庫` | `返品` | `1` | `[返却]=1`（下記） |
| `交換`（完全一致） | `交換納品` | `貸出中` | `交換納品` | `0` | 変更なし |
| `交換`（完全一致） | `交換返品` | `整備中` | `交換返品` | `0` | 変更なし |
| それ以外（`<配達>`・`来店(納品)` 等） | （不要） | `貸出中` | `納品` | `0` | 変更なし |

※ `交換（配達）` / `交換（引取）` / `ｷｬﾝｾﾙ(引取)` 等は「交換」ではない（配達モードで処理）。
※ `来店(納品)` は配達と同じ納品モード、`来店(返品)` は引取と同じ返品モード。

### 納品明細の返却記録（引取／来店(返品) のみ）

既存の納品記録に返却したことを付ける。**他列は変更しない**（INSERT／DELETE もしない）。

| 項目 | 内容 |
|------|------|
| 検索条件 | 受付台帳の **顧客コード** ＋ **現場コード** ＋ `[tag_id]` が EPC と一致（`LTRIM/RTRIM`） |
| 更新 | 条件に合う行のうち `ISNULL([返却],0)=0` のものに **`[返却]=1`** |
| 複数行 | 条件一致の未返却行をすべて更新 |
| 該当なし | **警告のみ**（HTTP 200。在庫戻し・tag_table3 はコミット） |
| 既に返却済み | **警告のみ**（スキップ） |
| 顧客コードなし | **警告のみ**（納品明細更新不可） |

技術的な SQL 例外はトランザクション全体をロールバックする。

## レスポンス

### 200 OK

```json
{
  "receptionNo": "12345",
  "linked": 2,
  "deliveryReturnUpdated": 2,
  "warnings": [
    "EPC ...: 納品明細に該当する貸出記録がありません（返却=1 未更新）。"
  ]
}
```

| プロパティ | 説明 |
|------------|------|
| receptionNo | 受付番号 |
| linked | 実際に紐付け（INSERT）した件数。既処理スキップ分は含まない |
| deliveryReturnUpdated | 納品明細で `[返却]` を 0→1 にした行数。返品モード以外は 0 |
| warnings | 商品コード不一致・既処理スキップ・納品明細該当なしなど（HTTP は成功） |

### エラー

| 状態 | 条件 |
|------|------|
| 400 | items 空、epc 空、受付番号が数値でない、用件「交換」で link_mode 不正 |
| 404 | 受付伝票なし、または ICタグ台帳に無い EPC |
| 409 | 読み取り専用 DB |

## 関連テーブル

| テーブル | 操作 |
|----------|------|
| [受付台帳] | 存在確認・顧客コード／現場コード取得 |
| [用件台帳] | 用件取得（モード判定） |
| [受付明細] | 商品コード警告用（読取のみ） |
| [ICタグ台帳] | `tag_mode2` を更新 |
| [tag_table3] | 受付番号付き INSERT |
| [納品明細] | 返品モード時のみ `[返却]=1` に UPDATE |

※ ステータス更新ログ用の [tag_table4] は使わない。
※ `[返却済]` 等の他列は触らない。

実装: `Controllers/ReceptionSlipsController.cs`（`LinkTags`）

検証 SQL:
- 配達（・来店(納品)）: `scripts/verify-link-tags-for-delivery.sql`
- 引取（・来店(返品)）: `scripts/verify-link-tags-for-pickup.sql`
- 交換: `scripts/verify-link-tags-for-exchange.sql`
