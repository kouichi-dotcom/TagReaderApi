# 担当者 API

[担当者台帳] から担当者コード・担当者氏名を取得する API。

## エンドポイント一覧

| メソッド | パス | 説明 |
|----------|------|------|
| GET | `/api/employees` | 担当者コード 1 件取得（クエリ `code` 必須） |
| GET | `/api/employees/all` | 担当者一括取得（範囲指定、初回キャッシュ用） |

---

## GET /api/employees（1件取得）

担当者コードをキーに担当者氏名を取得する。

### クエリパラメータ

| パラメータ | 型 | 必須 | 説明 |
|------------|-----|------|------|
| `code` | string | ○ | 担当者コード（数値として解釈） |

### レスポンス

- **200** … `{ "employeeCode": number, "employeeName": string }`
- **400** … code 未指定 or 数値でない
- **404** … 該当する担当者がいない

---

## GET /api/employees/all（一括取得）

`0 < 担当者コード <= maxCode` の範囲で [担当者台帳] の担当者を一括取得する。アプリの初回起動時キャッシュ用。

### クエリパラメータ

| パラメータ | 型 | 必須 | デフォルト | 説明 |
|------------|-----|------|------------|------|
| `minCode` | int | - | 1 | 最小担当者コード（1 以上） |
| `maxCode` | int | - | 101 | 最大担当者コード（minCode 以上） |

### レスポンス

- **200** … `[{ "employeeCode": number, "employeeName": string }, ...]`（担当者コード昇順）
- **400** … minCode / maxCode が条件を満たさない

### 例

- `GET /api/employees/all` … 1〜101 の範囲で全件取得
- `GET /api/employees/all?minCode=1&maxCode=200` … 1〜200 の範囲で取得
